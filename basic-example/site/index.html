Basic example

A tiny static app, plain HTML and React, with no server of its own. It uses dg.run for sign-in and for storing data.

Guestbook

Anyone can read the guestbook. Sign in to leave a message; you can delete your own.

My notes

Only you can see these. They are stored in the database, private to your account.

Built with the dg.run sign-in and database.
