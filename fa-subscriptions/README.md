# fa-subscriptions

نمونه‌ای کوچک و فارسی (راست‌به‌چپ) از **فروش اشتراک با dg.run**. کاربر یکی از طرح‌ها را انتخاب می‌کند، پرداخت را در dg.run انجام می‌دهد و صفحه‌ی برنامه باز می‌گردد و دسترسی را بررسی می‌کند.

- **آزمایش رایگان**، **اشتراک دوره‌ای** و **خرید یک‌باره** (تا همیشگی) — همه از روی طرح‌هایی که در پیشخوان می‌سازید.
- قیمت‌ها از `dg.billing.plans()` می‌آیند؛ چیزی در کد سخت‌کد نشده است. دلار و ریال هر دو نمایش داده می‌شوند.
- «وضعیت اشتراک شما» تاریخ تمدید، روزهای باقی‌مانده‌ی آزمایش، حالت همیشگی، پایان دوره و خطای کیف پول را نشان می‌دهد.
- با یک طرح فعال، «محتوای ویژه» باز می‌شود. این بررسی با `dg.billing.entitlement()` (اثبات امضاشده روی دستگاه) انجام می‌شود، پس آفلاین هم کار می‌کند.
- اگر کاربر پیش از ورود طرحی انتخاب کند، پس از ورود همان طرح یک‌بار خودکار باز می‌شود.

```ts
const plans = await dg.billing.plans()       // طرح‌ها (بدون ورود هم خوانده می‌شود)
const sub = await dg.billing.status()        // null یا { active, plan, currentPeriodEnd, autoRenew, trial, renewalError }
if (sub?.active) { /* امکانات پولی را باز کنید */ }

await dg.billing.subscribe('monthly')        // کاربر به dg.run می‌رود، می‌پردازد و برمی‌گردد
await dg.billing.cancel()                    // توقف تمدید خودکار؛ دسترسی تا پایان دوره می‌ماند
const ended = await dg.billing.checkout      // پس از بازگشت: { result: 'ok' | 'cancel' } یا null
```

صفحه‌ی شما هرگز پول جابه‌جا نمی‌کند. کاربر با نشست خودش در dg.run تأیید می‌کند؛ برنامه فقط می‌تواند طرح‌ها و وضعیت را بخواند، تمدید را متوقف کند و از کاربر *بخواهد* برود بپردازد.

## اجرا در محیط توسعه

```bash
npm install                  # یک‌بار، در ریشه‌ی مخزن
npm run dev                  # بازار، http://localhost:3000
cd examples/fa-subscriptions
npm install                  # dgclient را از npm نصب میکند
npm run pack                 # -> fa-subscriptions.zip (فایل از پیش ساخته هم موجود است)
```

1. در `/login` وارد شوید (کد `55555`) → **برنامه‌های من** → زیردامنه‌ی `fa-subscriptions` را با فایل `fa-subscriptions.zip` ثبت کنید.
2. دکمه‌ی **طرح‌ها** روی ردیف برنامه → این طرح‌ها را بسازید (کلید · نوع · قیمت):

   | کلید | نام | نوع | قیمت | توضیح |
   |---|---|---|---|---|
   | `trial` | آزمایش رایگان | آزمایش رایگان | رایگان | ۷ روز |
   | `monthly` | ماهانه | اشتراک | ۹.۰۰ دلار | هر ۱ ماه |
   | `yearly` | سالانه | اشتراک | ۹۰.۰۰ دلار | هر ۱ سال |
   | `lifetime` | همیشگی | خرید یک‌باره | ۱۹۹.۰۰ دلار | ۰ روز (= همیشگی) |
   | `rial-monthly` | ماهانه ریالی | اشتراک | ۵۰۰٬۰۰۰ ریال | هر ۱ ماه |

3. به‌عنوان مدیر، در `/admin/projects` نسخه را **آزمایش** کنید (در پیش‌نمایش فقط آزمایش رایگان کار می‌کند) و تأییدش کنید.
4. **http://fa-subscriptions.localhost:3000/** را باز کنید، وارد شوید و یک طرح انتخاب کنید. بدون کلید Stripe، پرداخت با کارت **شبیه‌سازی** می‌شود و پولی جابه‌جا نمی‌شود. برای پرداخت از کیف پول، ابتدا در **نمایه** (کارت شبیه‌سازی‌شده) پول اضافه کنید یا به‌عنوان مدیر در **تراکنش‌ها** کاربر را شارژ کنید.

## نکته‌ها

- **محدودیت رایگان این‌جا فقط برای نمایش است.** برنامه کد ثابت است و در مرورگر کاربر اجرا می‌شود، پس کاربر می‌تواند آن را تغییر دهد. `status().active` را سرور تصمیم می‌گیرد، اما کاری که صفحه‌تان با آن می‌کند فقط به اندازه‌ی خود صفحه معتبر است. برای محافظت واقعی، آنچه مهم است را در سمت سروری که کنترل می‌کنید محدود کنید و از این مقدار برای «نمایش» استفاده کنید.
- هر طرح به یک ارز قیمت‌گذاری می‌شود (`USD` یا `IRR`) و از موجودی همان ارز پرداخت می‌شود؛ هیچ‌چیز تبدیل نمی‌شود. کارت (Stripe) فقط برای دلار است.
- اشتراک‌ها از **کیف پول** تمدید می‌شوند. پرداخت با کارت یک دوره می‌خرد؛ تمدیدهای بعدی از کیف پول انجام می‌شوند.
- قیمت و مدت یک طرح پس از ساخته‌شدن تغییر نمی‌کند. برای تغییر قیمت، طرح تازه بسازید و قدیمی را بایگانی کنید.

برای توضیح کامل، [طرح‌ها و اشتراک‌ها](https://dg.run/docs/subscriptions) را ببینید. نمونه‌ی انگلیسی و کامل‌تر: `examples/pro-notes`.
